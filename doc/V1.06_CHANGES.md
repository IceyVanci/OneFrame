## 一、Type H 样式创建

### 设计说明

新增 Type H 样式（全画幅叠加文字），基于 Type G 但移除白色边框，Logo 和文字直接叠加在照片内部底部。

**与 Type G 的关键差异：**

| 特性 | Type G | Type H |
|------|--------|--------|
| 画布大小 | 图片高度 ÷ 0.8（横向）/ 0.9（纵向） | 图片原始大小（无额外白色区域） |
| 照片区域 | 92%×80%，顶部 5% 留白 | 100%×100% 填满画布 |
| 纵向图片 | 白色区域减半 | 不做任何调整 |
| 文字/Logo | 叠加在底部白色区域 | 叠加在照片底部内部 |
| 文字颜色 | 黑色 #000000 | 白色 #ffffff（在照片上更易读） |
| 背景色 | 白色 #ffffff | 黑色 #000000（照片填满，背景不可见） |
| 编辑面板 | 隐藏开关，显示 Logo 选择 | 完全相同 |

### Type H Logo 大小规则

与 Type G 相同的公式（相对于画布的比例）：
- Logo 最大高度 = 画布高度的 2.5%（即 `canvasHeight × 0.025`）
- 宽度：按原始宽高比自动计算

由于 Type H 的画布 = 图片原始大小，Logo 实际尺寸会比 Type G 略小（Type G 的画布是图片的 1.25 倍）。

### 技术细节

**预览端 `calcSize()`：**
```javascript
// Type G: canvasHeight = naturalHeight / 0.8
// Type H: canvasHeight = naturalHeight（无除法）
return { squareSize: naturalWidth, canvasHeight: naturalHeight };
```

**导出端 `renderImage()`：**
```javascript
// Type G: canvasHeight = naturalHeight / 0.8，照片绘制为 92%×80%
// Type H: canvasHeight = naturalHeight，照片绘制为 100%×100%
```

**文字颜色：**
- Type G CSS 使用 `color: #000000`（黑色，在白色背景上）
- Type H CSS 使用 `color: #ffffff`（白色，在照片上更易读）
- 导出端 `drawText()` 默认 color 为 `#ffffff`

### 编辑面板

与 Type G 完全相同：
- 隐藏边框颜色/高度/比例设置
- 隐藏所有显示开关（默认激活）
- 保留 Logo 选择区域
- 设备型号 placeholder 为"型号（如 A7M4）"

### 测试验证

| 测试项 | 预期结果 |
|--------|----------|
| 导入横向图片 | 照片填满画布，无白色边框 |

| Logo 显示 | 居中在照片底部，白色 |

| 导出图片 | 与预览一致 |
| 切换回其他样式 | 不受影响 |

## 二、文字颜色选择功能迁移（Type G → Type H）

### 背景

Type G（白底+照片）的文字颜色固定为黑色，在白色背景上始终可读，不需要颜色选择。
Type H（照片填满画布，文字叠加）的文字颜色默认为白色，但在浅色照片上可能看不清，因此需要用户手动选择黑/灰/白文字颜色。

### 修改文件

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `src/renderer/index.html` | 修改 | `#textColor` 默认值改为 `#ffffff`，active 按钮改为白色，注释改为"仅 Type H 显示"，版本号更新为 v1.0.6 |
| `src/renderer/js/components/type-g-editor-panel.js` | 修改 | 移除 `addTextColorPicker()` 函数和调用 |
| `src/renderer/js/components/type-h-editor-panel.js` | 修改 | 添加显示 `#textColorSection` 的代码，默认激活白色按钮 |
| `src/renderer/js/styles/type-g-preview.js` | 修改 | 移除 `textColor` 使用，恢复纯黑 `#000000` |
| `src/renderer/js/styles/type-g-export.js` | 修改 | 移除 `textColor` 使用，恢复纯黑 `#000000` |
| `src/renderer/js/styles/type-h-preview.js` | 修改 | 添加 `textColor` 支持（默认 `#ffffff`），line2/line3/separator 使用 inline style |
| `src/renderer/js/styles/type-h-export.js` | 修改 | `drawBorderContent()` 使用 `settings.textColor \|\| '#ffffff'` |
| `src/renderer/css/type-h.css` | 修改 | 添加注释说明 CSS color 为 fallback，由 JS inline style 覆盖 |

### 兼容性

- `app.js` 和 `exporter.js` 无需修改，`textColor` 作为通用字段传递
- 其他样式（Type A-F）不受影响，`#textColorSection` 对它们保持 `display:none`
