### #1.2 loadImageInElectron 遗漏 applyDynamicBackground — ✅ 已修复

**文件**：`src/renderer/js/app.js` — `loadImageInElectron` 函数

**修复前**：
```javascript
if (userImage.complete) {
  updateExifDisplay();
  updateBorder();
} else {
```

**修复后**：
```javascript
if (userImage.complete) {
  updateExifDisplay();
  updateBorder();
  applyDynamicBackground(userImage);
} else {
```

**说明**：当 Electron 环境下图片已缓存（`userImage.complete` 为 true）时，动态背景色函数不会被调用，导致编辑器背景色仍为预设颜色。

### #1.3 loadImageInElectron 重复设置 onload — ✅ 已修复

**文件**：`src/renderer/js/app.js` — `loadImageInElectron` 函数

**修复前**：
```javascript
userImage.onload = () => { updateExifDisplay(); updateBorder(); applyDynamicBackground(userImage); };
```

**修复后**：
```javascript
userImage.addEventListener('load', () => { updateExifDisplay(); updateBorder(); applyDynamicBackground(userImage); }, { once: true });
```

**说明**：
- `onload` 赋值每次调用会覆盖之前的值
- `addEventListener` 不会覆盖，但会在页面生命周期内累积
- 使用 `{ once: true }` 确保回调只执行一次，避免累积

### #1.4 checkImageOrientation 内存泄漏 — ✅ 已修复

**文件**：`src/renderer/js/app.js` — `checkImageOrientation` 函数

**修复前**：
```javascript
img.src = typeof fileOrPath === 'string' ? `file://${fileOrPath}` : URL.createObjectURL(fileOrPath);
```

**修复后**：
```javascript
const isBlob = typeof fileOrPath !== 'string';
const src = isBlob ? URL.createObjectURL(fileOrPath) : `file://${fileOrPath}`;
// onload/onerror 中添加：
if (isBlob) URL.revokeObjectURL(src);
```

**说明**：
- 传入 File 对象时会创建 ObjectURL，但从未调用 revokeObjectURL 释放内存
- 修复后在 onload 和 onerror 回调中添加 URL.revokeObjectURL(src)
- 仅对 blob URL（isBlob 为 true）执行释放，避免对 file:// URL 误操作

### #2.3 configureTypeX 映射表优化 — ✅ 已修复

**文件**：`src/renderer/js/app.js` — `showEditor` 函数

**修复前**（7 个独立 if 块）：
```javascript
if (currentStyle === 'type-f') { configureTypeF(); }
if (currentStyle === 'type-g') { configureTypeG(); }
// ... 共 7 个
```

**修复后**（映射表）：
```javascript
const panelConfigurers = {
  'type-f': configureTypeF, 'type-g': configureTypeG,
  'type-h': configureTypeH, 'type-i': configureTypeI,
  'type-j': configureTypeJ, 'type-k': configureTypeK,
  'type-l': configureTypeL
};
panelConfigurers[currentStyle]?.();
```

**说明**：将 7 个独立的 if 条件判断合并为一个映射表，使用可选链调用 `?.()`，减少代码重复并提升可维护性。

### #2.4 detectLogoBrightness 性能优化 — ✅ 已修复

**文件**：`src/renderer/js/app.js` — `detectLogoBrightness` 函数

**修复前**：
```javascript
canvas.width = img.width;
canvas.height = img.height;
```

**修复后**：
```javascript
canvas.width = 32;

```

**说明**：
- SVG Logo 可能具有很大的固有尺寸（如 1000×1000），全分辨率绘制浪费性能
- 亮度检测只需近似结果，32×32 分辨率已足够
- `ctx.drawImage(img, 0, 0)` 会自动将 SVG 缩放到 canvas 尺寸
