# OneFrame v1.0.3 更新发布！

一款简洁优雅的图片边框添加工具，为您的照片自动添加精美的底部边框，并智能显示相机的 EXIF 信息。

## ✨ 新功能

### 🖼️ Type F 画中画样式
- 新增第 6 种边框样式：上方 5% 白色留白 + 中部 92%×80% 照片展示区 + 下方 15% 文字信息区
- 文字区域使用绝对定位，署名显示/隐藏不影响前两行位置
- 窗口缩放时使用 `transform: scale()` 等比缩放，保持画布宽高比不变
- 字号动态缩放，预览与导出完全一致
- 文字内容：
  - 第一行："Shot on"（灰色）+ 品牌型号（黑色，自动从 EXIF 读取）
  - 第二行：日期 光圈 焦距 快门 ISO（灰色）
  - 第三行：© 署名（灰色，可选）

### ⚙️ Type F 编辑面板
- 隐藏边框颜色、边框高度、比例设置、Logo 区域（简化面板）
- 设备型号文本框自动包含品牌名（如 "Sony A7M4"）
- 拍摄参数开关控制焦距显示

### 🏷️ 首页更新
- "参数"分类新增 Type F 样式卡片
- 更新 Type E 和 Type F 的缩略图

## 📝 文档更新

- README.md 项目结构部分默认折叠，减少页面长度
- 更新 DESIGN.md、function_analysis.md 添加 Type F 说明
- 创建 doc/V1.03_CHANGES.md 详细修改说明文档
