# OneFrame v1.0.6 发布说明

**发布日期**：2026-06-23

---

## 🎉 新功能

### Type H 全画幅叠加文字样式
- 新增第八种边框样式，照片 100% 填满画布，Logo 和文字叠加在照片底部
- 画布大小 = 图片原始大小，无额外白色区域
- 适用于需要最大化照片展示面积的场景

### Type H 文字颜色选择
- Type H 编辑面板新增"文字颜色"选择区域（黑/灰/白）
- 默认白色文字，用户可根据照片背景自由切换
- 预览和导出同步应用用户选择的文字颜色

## 🔧 变更

- 文字颜色选择功能从 Type G 移至 Type H（Type G 白底黑字无需颜色选择）
- Type H 样式卡片使用专用预览图
- 版本号更新至 v1.0.6
