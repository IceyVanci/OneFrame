## 一、首页缩略图随机选择机制（核心功能）

### 设计说明

为首页样式卡片实现基于 `src/renderer/Sample/` 目录中 ID 前缀缩略图的随机选择机制。每次页面加载时，13 个样式卡片会从 `Sample/` 目录中随机选择不同 ID 的缩略图，确保同屏展示的样式卡片不会使用相同原始图片。

### 文件命名规则

`Sample/` 目录中的缩略图文件命名规则为：

```
{3位数字ID}-{TypeX}-sample_compressed.jpeg
```

示例：
- `022-TypeA-sample_compressed.jpeg`
- `002-TypeB-sample_compressed.jpeg`
- `011-TypeJ-sample_compressed.jpeg`

### 核心算法

1. **文件列表获取**：Electron 环境下通过 IPC 端点 `get-sample-files` 由主进程直接读取 `Sample/` 目录文件列表（高效模式）；浏览器环境下回退到 Image 对象逐个探测。
2. **候选筛选**：从文件列表中按样式名称筛选匹配的候选文件，通过 `isValidSampleFilename()` 正则过滤不符合命名规则的文件。
3. **全局去重分配**：使用 Fisher-Yates 洗牌算法随机打乱样式顺序和候选列表，为每个样式分配一个唯一 `imageId`，确保同屏不同样式不使用相同原始图片。
4. **回退机制**：当某个样式无可用候选或所有 ID 已被占用时，回退到 HTML 中的基础缩略图。

## 二、修复首页缩略图 404 和探测失败问题

### 问题描述

缩略图选择器核心算法完成后，运行时存在三个导致功能无法正常工作的问题：
- 页面加载时所有样式卡片图片 404；
- `fetch()` 在 Electron `file://` 协议下无法探测本地文件；
- 回退路径指向不存在的根目录文件。

### 修复方案

#### 1. index.html 默认缩略图路径修复

将所有 13 个样式卡片的 `<img src>` 从根目录路径（文件已不存在）改为 `Sample/` 目录下实际存在的文件路径：

```html
<!-- 修复前 -->
<img src="TypeA-sample_compressed.jpeg" ...>
<!-- 修复后 -->
<img src="Sample/022-TypeA-sample_compressed.jpeg" ...>
```

每个样式选择 `Sample/` 目录中该样式的一张实际存在的图片作为默认占位图。

#### 2. checkFileExists() 改用 Image 对象探测

将 `fetch()` 探测替换为 `Image` 对象加载探测，天然兼容 `file://` 协议：

```javascript
async function checkFileExists(url) {
  return new Promise((resolve) => {
    const img = new Image();
    const timeout = setTimeout(() => { img.src = ''; resolve(false); }, 2000);
    img.onload = () => { clearTimeout(timeout); resolve(true); };
    img.onerror = () => { clearTimeout(timeout); resolve(false); };
    img.src = url;
  });
}
```

#### 3. buildStyleThumbnailMeta() 保留 Sample/ 前缀

从 HTML `<img src>` 提取路径时保留完整相对路径（含 `Sample/` 前缀）作为回退路径，不再只取文件名：

```javascript
// 修复前：basePath = filename（如 '022-TypeA-sample_compressed.jpeg'）
// 修复后：basePath = src（如 'Sample/022-TypeA-sample_compressed.jpeg'）
```

#### 4. 新增 Electron IPC 文件列表读取（高效模式）

新增主进程 IPC 端点，直接读取 `Sample/` 目录文件列表返回给渲染端，避免逐个探测：

- `src/main/main.js`：新增 `get-sample-files` IPC 处理器，使用 `fs.readdirSync` 读取目录
- `src/main/preload.js`：暴露 `getSampleFiles` API
- `src/renderer/js/thumbnail-selector.js`：新增 `collectCandidatesFromFileList()` 函数，优先使用文件列表直接筛选候选，无 Electron 环境时回退到 Image 探测

## 三、首页样式卡片移除多余白色边框

### 问题描述

修复缩略图路径后，首页样式卡片图片下方出现了多余的白色条状区域。

### 根因分析

每个样式卡片内包含 `<div class="photo-footer"></div>` 元素，CSS 设置 `background: #fff`。之前图片 404 时该元素高度为 0（因为 `load` 事件不触发），修复路径后图片正常加载，JS 通过 `load` 事件设置了 `photo-footer` 高度为图片短边的 12%，白色条因此可见。

由于 `Sample/` 目录中的缩略图已经是包含完整边框效果的预览图，不需要额外的模拟边框。

### 修复方案

1. 从 `index.html` 中所有 13 个样式卡片内移除 `<div class="photo-footer"></div>` 元素。
2. 从 `app.js` 中移除首页 `photo-footer` 高度计算逻辑（`document.querySelectorAll('.style-preview .frame-container img').forEach(...)` 代码块）。

注意：编辑器视图中的 `<div class="photo-footer" id="photoFooter">` 保留不变，它是编辑器预览所需的功能元素。

### 修改文件

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `src/renderer/index.html` | 修改 | 移除 13 个样式卡片内的 photo-footer 元素 |
| `src/renderer/js/app.js` | 修改 | 移除首页 photo-footer 高度计算逻辑 |
