## 二、Type K 样式创建

### 设计说明

新增 Type K 样式（左下角 Logo + 双行文字），基于 Type H/I/J 的代码结构实现。

**布局：**
```
┌──────────────────────────────────────┐
│                                      │
│         照片 100% 填满画布            │
│                                      │
│ [Logo] © OneFrame  2024/01/01        │  ← 底部左下角
│        Sony A7M4  50mm f/2.8 1/125s  │
└──────────────────────────────────────┘
```

- Logo 在底部左下角（5% 起）
- Logo 右侧第一行：署名（medium）+ 日期（normal）
- Logo 右侧第二行：机型名称（medium）+ 拍摄参数（normal）
- 机型名称不含厂商前缀（使用默认 EXIF 读取逻辑）

**与 Type H 的关键差异：**

| 特性 | Type H | Type K |
|------|--------|--------|
| Logo 位置 | 底部居中 | 左下角 |
| 文字布局 | 三行居中（Logo + 参数行 + 署名） | 两行左对齐（Logo 右侧） |
| 字重 | 全部 normal | 署名/机型 medium，其余 normal |
| 机型名称 | 不含厂商 | 不含厂商 |
| 编辑面板 | 显示 Logo + 文字颜色 | 同 Type H |

## 三、Type K 导出修复

### Logo 纵向位置修复

**问题**：导出图像中 Logo 位置偏上，不在两行文字中间。

**根因**：`logoCenterY` 计算多减了 `lineHeight / 2`。

**修复**：
```javascript
// 修复前
const logoCenterY = bottomAnchorY - lineHeight - lineGap / 2 - lineHeight / 2;

// 修复后
const line2Y = bottomAnchorY - lineHeight / 2;
const line1Y = line2Y - lineHeight / 2 - lineGap - lineHeight / 2;
const logoCenterY = (line1Y + line2Y) / 2;
```

## 四、Type L 样式创建

### 设计说明

新增 Type L 样式（高斯模糊背景），基于 Type G 修改，将白色外框替换为照片的高斯模糊版本。

**与 Type G 的关键差异：**

| 特性 | Type G | Type L |
|------|--------|--------|
| 外框背景 | 白色 `#ffffff` | 照片高斯模糊 |
| 文字颜色 | 黑色 `#000000` | 白色 `#ffffff`（默认） |
| 照片区域 | 相同（92%×80%） | 相同 |
| 编辑面板 | 显示 Logo + 署名 | 同 Type G + 文字颜色选择 |

**Type L 布局：**
```
┌──────────────────────────────┐
│  ░░░░░░░░░░░░░░░░░░░░░░░░░░  │
│  ░░░░░░░░░░░░░░░░░░░░░░░░░░  │  ← 高斯模糊照片背景
│  ░░┌────────────────────┐░░  │
│  ░░│                    │░░  │
│  ░░│   清晰照片 92%×80%  │░░  │
│  ░░│                    │░░  │
│  ░░└────────────────────┘░░  │
│  ░░ [Logo] 日期|参数|机型 ░░  │  ← 白色文字
│  ░░      © 署名          ░░  │
└──────────────────────────────┘
```

### 技术实现

**预览端：**
- 动态创建 `<img class="type-l-blur-bg">` 作为模糊背景层
- CSS `filter: blur()` 实现高斯模糊，GPU 加速
- `transform: scale(1.5)` 从中心放大，解决 blur 透明边缘偏移问题
- `overflow: hidden` 裁剪溢出区域
- `background: #000` 让 blur 透明边缘与黑色背景融合

**导出端：**
- Canvas `ctx.filter = 'blur()'` 两步绘制
- 第一步：全画幅模糊背景（cover 裁剪）
- 第二步：清晰照片 92%×80% 居中
- 第三步：绘制白色文字内容

### 预览端 blur 修复记录

| 轮次 | 问题 | 修复 |
|------|------|------|
| 1 | blur 背景被前景照片 CSS 覆盖 | 选择器改为 `img:not(.type-l-blur-bg)` |
| 2 | 右侧和底边透明 | 增大溢出量 110%→120%→130% |
| 3 | 透明区域更大 | `overflow: hidden` + `background: #000` |
| 4 | 背景偏左上方 | 改用 `transform: scale(1.5)` 替代负偏移 |
| 5 | 仍然偏上 | 确认 scale(1.5) 修复，每边 25% 溢出量 |
