## 一、编辑器动态背景色

### 设计说明

导入图片后，编辑器预览区背景色自动根据图片主色调生成，替代原来的固定预设背景色 `#16213e`。

### 技术实现

**新增函数 `applyDynamicBackground(img)`：**

```javascript
function applyDynamicBackground(img) {
  const target = document.querySelector('.preview-area');
  if (!target) return;
  try {
    const canvas = document.createElement('canvas');
    canvas.width = 10;
    canvas.height = 10;
    const ctx = canvas.getContext('2d');
    ctx.drawImage(img, 0, 0, 10, 10);
    const imageData = ctx.getImageData(0, 0, 10, 10).data;
    let r = 0, g = 0, b = 0, count = 0;
    for (let i = 0; i < imageData.length; i += 4) {
      r += imageData[i];
      g += imageData[i + 1];
      b += imageData[i + 2];
      count++;
    }
    r = Math.round(r / count * 0.4);
    g = Math.round(g / count * 0.4);
    b = Math.round(b / count * 0.4);
    target.style.backgroundColor = `rgb(${r}, ${g}, ${b})`;
  } catch (e) {
    target.style.backgroundColor = '#16213e';
  }
}
```

**算法说明：**
1. 将图片绘制到 10×10 canvas（极低分辨率，性能友好）
2. 遍历 100 个像素，计算平均 R/G/B 值
3. 乘以 0.4 系数压暗（避免背景太亮干扰前景预览）
4. 设置为 `.preview-area` 的 `backgroundColor`

### 调用时机

| 位置 | 触发条件 | 说明 |
|------|----------|------|
| `showEditor()` | `userImage.complete` 为 true | 编辑器打开且图片已缓存时 |
| `userImage.addEventListener('load')` | 图片加载完成 | 浏览器环境图片加载 |
| `loadImageInElectron` 的 `onload` | 图片加载完成 | Electron 环境图片加载 |

### 效果示例

- 暖色调照片（日落）→ 深橙/棕色背景
- 冷色调照片（海景）→ 深蓝色背景
- 绿色植物照片 → 深绿色背景
- 人像照片 → 根据肤色/背景色自动适配

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `src/renderer/js/app.js` | 修改 | 新增 `applyDynamicBackground` 函数，3 处调用点 |

## 二、Type E 横向图片右侧参数位置修复

### 问题描述

Type E 样式导入横向图片时，右侧参数（光圈/焦距/快门/ISO/机型/署名）位置偏移，未与左侧年份文字顶部对齐。

### 根因分析

`type-E-preview.js` 的 `updateContentPreview` 中使用 `getBoundingClientRect()` 计算右侧参数的 `marginTop`：

```javascript
// 修复前
const yearRect = yearEl.getBoundingClientRect();
const paramsRect = paramsEl.getBoundingClientRect();
paramsEl.style.marginTop = `${yearRect.top - paramsRect.top}px`;
```

`getBoundingClientRect()` 返回**视口坐标**，受 CSS `transform` 影响。当浏览器窗口缩放导致 `frameWrapper` 或其祖先元素有 transform 时，计算出的偏移值不准确。

### 修复方案

改用 `offsetTop`（相对于 offsetParent，不受 transform 影响）：

```javascript
// 修复后
const yearOffset = yearEl.offsetTop;
const paramsOffset = paramsEl.offsetTop;
paramsEl.style.marginTop = `${yearOffset - paramsOffset}px`;
```

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `src/renderer/js/styles/type-E-preview.js` | 修改 | 第 238-241 行，`getBoundingClientRect()` → `offsetTop` |
