## 一、主界面图片墙重构

**改造前布局（单列）：**

```
│    [参数] [海报]              │

│ ┌──────────────────────────┐ │
│ │      Type A 预览图        │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │      Type B 预览图        │ │
│ └──────────────────────────┘ │
│ ...                          │
```

### JS 变更

删除 `app.js` 中的标签页筛选逻辑：
```javascript
// 删除以下代码
const tabBtns = document.querySelectorAll('.tab-btn');
const allStyleCards = document.querySelectorAll('.style-card');

function filterCards(category) {
  allStyleCards.forEach(card => {
    if (card.dataset.category === category) {
      card.classList.remove('hidden');
    } else {
      card.classList.add('hidden');
    }
  });
}

tabBtns.forEach(btn => {
  btn.addEventListener('click', () => {
    tabBtns.forEach(b => b.classList.remove('active'));
    btn.classList.add('active');
    filterCards(btn.dataset.tab);
  });
});

filterCards('params');
```

## 二、Type K/L 编辑面板改进

### 设备型号输入框显示

Type K 和 Type L 编辑面板现在显示设备型号输入框，方便用户手动修改机型名称。

**Type K 修改（`type-K-editor-panel.js`）：**
```javascript
// 改造前
// 设备型号：隐藏（EXIF 自动读取，不含厂商前缀）
const modelSection = document.querySelector('.edit-section:has(#customModel)');
if (modelSection) modelSection.style.display = 'none';

// 改造后
// 设备型号：显示（EXIF 自动读取，用户可手动修改）
const customModel = document.getElementById('customModel');
if (customModel) {
  customModel.placeholder = '型号（如 A7M4）';
}
```

**Type L 修改（`type-L-editor-panel.js`）：**
```javascript
// 改造前
```

## 三、文件名大写化

### 设计说明

将所有样式相关文件名中的样式字母从小写改为大写（如 `type-a.css` → `type-A.css`），避免与 CSS 类名中的小写字母混淆。

**命名规范：**
- **文件名**：大写（`type-A.css`、`type-A-preview.js`、`type-A-export.js`、`type-A-editor-panel.js`）
- **CSS 类名**：小写（`.type-a`、`.frame-wrapper.type-a`）
- **data-style 属性**：小写（`data-style="type-a"`）
- **JS 样式 ID**：小写（`currentStyle === 'type-a'`、`classList.add('type-a')`）
- **import 路径**：大写（`'./type-A-preview.js'`）

### 重命名文件清单（48个）

**CSS 文件（12个）：**

| 原文件名 | 新文件名 |
|----------|----------|
| `css/type-a.css` | `css/type-A.css` |
| `css/type-b.css` | `css/type-B.css` |
| `css/type-c.css` | `css/type-C.css` |
| `css/type-d.css` | `css/type-D.css` |
| `css/type-e.css` | `css/type-E.css` |
| `css/type-f.css` | `css/type-F.css` |
| `css/type-g.css` | `css/type-G.css` |
| `css/type-h.css` | `css/type-H.css` |

**预览模块（12个）：** `type-x-preview.js` → `type-X-preview.js`（x = a~l, X = A~L）

**导出模块（12个）：** `type-x-export.js` → `type-X-export.js`

**编辑面板（12个）：** `type-x-editor-panel.js` → `type-X-editor-panel.js`

### 更新引用的文件

| 文件 | 变更说明 |
|------|----------|
| `src/renderer/index.html` | CSS 链接路径：`css/type-c.css` → `css/type-C.css` 等 |
| `src/renderer/index.css` | @import 路径：`@import url('css/type-a.css')` → `@import url('css/type-A.css')` 等 |
| `src/renderer/js/styles/index.js` | import 路径：`'./type-a-preview.js'` → `'./type-A-preview.js'` 等（24 处） |
| `src/renderer/js/exporter.js` | import 路径：`'./styles/type-a-export.js'` → `'./styles/type-A-export.js'` 等（12 处） |
| `src/renderer/js/app.js` | import 路径：`'./components/type-f-editor-panel.js'` → `'./components/type-F-editor-panel.js'` 等（7 处） |

### 注意事项

CSS 类名和 `data-style` 属性保持小写不变，这是为了：
1. `app.js` 中 `currentStyle === 'type-a'` 的比较逻辑无需修改
2. `classList.add('type-a')` 的 DOM 操作无需修改
3. CSS 选择器 `.frame-wrapper.type-a` 无需修改
4. `index.js` 中 `styles['type-a']` 的注册表 key 无需修改
