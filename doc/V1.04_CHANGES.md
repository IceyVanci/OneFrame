# OneFrame v1.0.4 实际修改说明

**日期**：2026-06-19

---

## 修复 Type F 预览缩放问题

### 问题描述

Type F（画中画样式）的预览界面存在多个缩放相关问题：

1. **窗口大小变化后图框与图片相对位置/比例关系错乱**：缩放窗口后，图框不能正确等比缩放，图片与图框的比例关系发生变化
2. **非初始窗口大小下导入图片时图框比例错误**：在非默认窗口大小下导入图片，图框显示比例不正确
3. **横向窗口变小时图框不缩放**：窗口横向缩小后，图框只减小横向宽度而不等比缩放
4. **纵向窗口变大时横向不跟随**：窗口纵向放大后，图框只增大纵向高度，图片被放大但横向宽度不变

### 根因分析

本次修复涉及两个独立的问题：

#### 问题 1：双重缩放（calcSize + transform: scale）

`type-f-preview.js` 的 `calcSize()` 函数在内部获取了预览区域尺寸（`previewArea.clientWidth/clientHeight`），计算缩放比后返回**已缩小的像素值**。而 `app.js` 的 `updateBorder()` Type F 分支又对这些已缩小的值应用了 `transform: scale()`。

**代码路径（修复前）：**
```
calcSize() 获取预览区域尺寸 → 计算缩放比 → 返回已缩小的值（如 346×576）
    ↓
typeFCachedSize = { squareSize: 346, canvasHeight: 576 }
    ↓
updateFrameWrapper(346, 576) → frameWrapper 布局尺寸 = 346×576
    ↓
transform: scale(0.7) → 视觉缩放，但布局尺寸仍为 346×576
    ↓
问题：窗口变大时 scale 被 Math.min(..., 1) 限制，frameWrapper 无法放大
问题：窗口变小时双重缩放，比例错乱
```

**关键问题**：`transform: scale()` 只改变视觉大小不改变布局大小，与 CSS 百分比定位（`width:92%`, `height:80%`）和父容器 `overflow: hidden` 产生冲突。图片的 `width: 92%` 是相对于 frameWrapper 的**布局尺寸**（346px）而非视觉尺寸计算的。

#### 问题 2：CSS 选择器意外匹配（type-a.css → type-f）

`type-a.css` 中有一条通用选择器规则：

```css
.frame-wrapper.type-a,
.frame-wrapper:not(.type-b):not(.type-e) {
  max-width: 900px;
  width: 100%;
  max-height: 100%;
  display: flex;
  ...
}
```

这个选择器匹配了所有不带 `.type-b` 和 `.type-e` 的 frame-wrapper，包括 Type F。因此 Type F 的 frameWrapper 被施加了：
- `max-width: 900px` — 限制了图框最大宽度
- `width: 100%` — 窗口变窄时覆盖 JS 设置的 width
- `max-height: 100%` — 限制了图框最大高度

这导致：
- 横向窗口变窄时，CSS 的 `width: 100%` 覆盖 JS 设置的宽度，图框只缩小横向
- 纵向窗口变大时，宽度被 `max-width: 900px` 或 `width: 100%` 限制，图框只增大纵向

### 修复方案

#### 修改 1：`type-f-preview.js` — calcSize() 移除预览缩放

```javascript
// 修改前：内部做了预览缩放
export function calcSize(settings) {
  const { naturalWidth, naturalHeight } = settings;
  const canvasWidth = naturalWidth;
  const canvasHeight = Math.round(naturalHeight / 0.8);
  const previewArea = state.frameWrapper?.parentElement;
  const availWidth = previewArea?.clientWidth || 500;
  const availHeight = previewArea?.clientHeight || 600;
  const maxWidth = availWidth * 0.96;
  const maxHeight = availHeight * 0.96;
  const scale = Math.min(maxWidth / canvasWidth, maxHeight / canvasHeight);
  let squareSize, margin;
  if (scale < 1) {
    squareSize = Math.round(canvasWidth * scale);
    margin = Math.round(canvasHeight * scale);
  } else {
    squareSize = canvasWidth;
    margin = canvasHeight;
  }
  return { squareSize, margin, canvasHeight: scale < 1 ? margin : canvasHeight };
}

// 修改后：只返回原始画布尺寸
export function calcSize(settings) {
  const { naturalWidth, naturalHeight } = settings;
  const canvasWidth = naturalWidth;
  const canvasHeight = Math.round(naturalHeight / 0.8);
  return { squareSize: canvasWidth, canvasHeight };
}
```

#### 修改 2：`app.js` — updateBorder() Type F 分支

```javascript
// 修改前：使用 transform: scale()
const { squareSize: fSize, canvasHeight: fH } = typeFCachedSize;
preview.updateFrameWrapper(fSize, fH);
preview.updatePreview(fSize, fH, { ... });
const previewArea = frameWrapper?.parentElement;
if (previewArea) {
  const availW = previewArea.clientWidth * 0.96;
  const availH = previewArea.clientHeight * 0.96;
  const needScale = Math.min(availW / fSize, availH / fH, 1);
  frameWrapper.style.transformOrigin = 'top center';
  frameWrapper.style.transform = needScale < 1 ? `scale(${needScale})` : 'none';
}

// 修改后：每次 resize 动态计算显示尺寸
const { squareSize: canvasW, canvasHeight: canvasH } = typeFCachedSize;
const previewArea = frameWrapper?.parentElement;
const availW = (previewArea?.clientWidth || 500) * 0.96;
const availH = (previewArea?.clientHeight || 600) * 0.96;
const displayScale = Math.min(availW / canvasW, availH / canvasH, 1);
const displayW = Math.round(canvasW * displayScale);
const displayH = Math.round(canvasH * displayScale);
preview.updateFrameWrapper(displayW, displayH);
preview.updatePreview(displayW, displayH, { ... });
frameWrapper.style.transform = 'none';
```

#### 修改 3：`type-f.css` — 覆盖继承的 CSS 约束

```css
/* 修改前 */
.frame-wrapper.type-f {
  display: block !important;
  position: relative;
  background: #ffffff;
  /* 尺寸由 JS 动态设置 */
}

/* 修改后 */
.frame-wrapper.type-f {
  display: block !important;
  position: relative;
  background: #ffffff;
  /* 覆盖 type-a.css 中 .frame-wrapper:not(.type-b):not(.type-e) 继承的属性 */
  max-width: none !important;
  max-height: none !important;
  /* 尺寸由 JS 通过 inline style 设置 */
}
```

### 修复原理

**核心原则**：所有元素的缩放比例完全相同，以维持相对大小和位置不变。

1. `calcSize()` 返回原始画布尺寸（与导出 Canvas 尺寸一致）
2. `typeFCachedSize` 缓存原始尺寸（不受窗口大小影响）
3. 每次 resize 时：`displayScale = min(availW / canvasW, availH / canvasH, 1)`
4. `displayW = canvasW × displayScale`，`displayH = canvasH × displayScale`
5. frameWrapper 布局尺寸 = `displayW × displayH`
6. CSS 百分比定位（图片 92%×80%、文字区 15%）自动按 frameWrapper 尺寸计算
7. 字号 = `14 × displayW / 900`，跟随显示宽度

**无 transform，无双重缩放，所有元素同比例缩放。**
