## 新增 Type F 边框样式

### 布局设计

```
┌──────────────────────────────────────┐
│          上方白色留白区 (5%)           │
├──────┬────────────────────┬──────────┤
│  4%  │                    │   4%     │
│      │    照片展示区       │          │  ← 92% 宽度，80% 高度
│      │                    │          │
├──────┴────────────────────┴──────────┤
│         下方文字信息区 (15%)           │  ← 绝对定位，居中对齐
└──────────────────────────────────────┘
```

- 画布比例 = 图片比例（宽度 = 图片宽度，高度 = 图片高度 / 0.8）
- 文字区域使用绝对定位，确保署名不影响前两行位置
- 窗口缩放时使用 `transform: scale()` 保持宽高比

### 文字内容

- **第一行**："Shot on"（灰色 #888）+ 品牌型号（黑色 #000）
- **第二行**：日期 光圈 焦距 快门 ISO（全部灰色 #888）
- **第三行**：© 署名（灰色 #888，可选，署名为空不显示）
- 字号动态缩放（基准 900px 宽度对应 14px）

### 编辑面板

- 隐藏边框颜色、边框高度、比例设置、Logo 区域
- 设备型号文本框自动包含品牌名（如 "Sony A7M4"）
- 拍摄参数开关控制焦距显示

## 关键技术实现

### 预览与导出一致的位置计算

预览和导出使用完全相同的绝对定位计算逻辑：

```javascript
const groupHeight = (line1 ? lineHeight1 : 0) + lineGap + (line2 ? lineHeight2 : 0);
const centerY = textAreaHeight / 2;
const line1Top = centerY - groupHeight / 2;
const line2Top = line1Top + lineHeight1 + lineGap;
const line3Top = line2Top + lineHeight2 + signatureGap;
```

### 窗口缩放处理

图片加载时缓存图框尺寸，resize 时使用缓存值 + `transform: scale()` 等比缩放：

```javascript
const needScale = Math.min(availW / fSize, availH / fH, 1);
frameWrapper.style.transform = needScale < 1 ? `scale(${needScale})` : 'none';
```

### 字号动态缩放

```javascript
const fontSize = Math.max(8, Math.round(14 * squareSize / 900));
borderContent.style.fontSize = `${fontSize}px`;
```

CSS 使用 `em` 单位（`font-size: 1em`、`0.8571em`）确保相对比例正确。
