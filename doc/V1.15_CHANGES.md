## 一、新增 Type N 样式

### 背景

基于 Type G 样式创建新的 Type N 样式，实现上下对称边框布局，Logo 移至顶部，简化底部信息显示。

### 设计规格

Type N 与 Type G 共享左右图框比例（92% 宽度，左右各 4%），但上下边框对称分配：

| 区域 | 横向图片 | 纵向图片 |
|------|----------|----------|
| 顶部白色边框（Logo） | 7.5% | 3.75% |
| 照片展示区 | 85% | 92.5% |
| 底部文字区（参数+署名） | 7.5% | 3.75% |

### 与 Type G 的差异

| 特性 | Type G | Type N |
|------|--------|--------|
| 顶部留白 | 5%（无内容） | 7.5%（Logo 居中） |
| 照片高度 | 80%（横向）/ 90%（纵向） | 85%（横向）/ 92.5%（纵向） |
| 底部文字区 | 15%（横向）/ 7.5%（纵向） | 7.5%（横向）/ 3.75%（纵向） |
| Logo 位置 | 底部文字区第一行 | 顶部边框内居中 |
| 时间显示 | ✅ 有 | ❌ 无 |
| 机型显示 | ✅ 有 | ❌ 无 |
| 参数格式 | `f/1.8 \| 50mm \| 1/100s \| ISO100` | `Aperture f/1.8 Focal 50mm Shutter 1/100s ISO 100` |
| 参数字重 | Medium (500) | 标签 Medium (500) + 数值 Normal (400) |
| 署名位置 | 与参数整体居中 | 固定在参数行下方，不随有无署名影响参数位置 |

## 二、文字排版设计

### 混合字重方案

参数行采用混合字重，提升可读性：

- **标签部分**（Aperture / Focal / Shutter / ISO）：`MiSans Medium`（weight 500）
- **数值部分**（f/1.8 / 50mm / 1/100s / 100）：`MiSans Normal`（weight 400）
- **署名行**（© xxx）：`MiSans Normal`（weight 400）

### 参数格式

每个参数前加英文标签，参数之间用空格分隔（无竖线）：

```
Aperture f/1.8  Focal 50mm  Shutter 1/100s  ISO 100
```

### 布局行为

- 参数行固定在底部文字区垂直居中
- 署名行始终在参数行下方固定间距
- 有/无署名时，参数行位置不变

## 三、编辑面板配置

Type N 编辑面板隐藏以下控件（与 Type G 类似）：

- 边框颜色（固定白色）
- 边框高度
- 比例设置
- 设备型号输入框
- 时间设置（日期时间输入框及开关）

保留显示：

- Logo 设置区域（含 Logo 选择网格）
- 拍摄参数（f/光圈、快门、焦距、ISO）
- 署名文字

## 五、维护说明

Type N 样式遵循与其他样式（Type F~M）相同的模块化架构：

- 预览逻辑在 `type-N-preview.js`，导出逻辑在 `type-N-export.js`
- 样式注册在 `styles/index.js` 和 `exporter.js`
- 主程序 `app.js` 中通过 `else if (currentStyle === 'type-n')` 分支处理
- 编辑面板配置在 `type-N-editor-panel.js`，通过 `panelConfigurers` 映射调用
