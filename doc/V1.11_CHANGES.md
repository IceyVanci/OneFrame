## 二、关于界面链接系统浏览器打开

### 设计说明

关于模态框中的链接（GitHub、Bilibili、Instagram）点击后从系统默认浏览器打开，而非在 Electron 窗口内导航。

### 技术实现

**1. 主进程（`src/main/main.js`）：**

新增 `shell` 导入和 `open-external` IPC 处理器：

```javascript
const { app, BrowserWindow, ipcMain, dialog, shell } = require('electron');

// 在系统浏览器中打开链接
ipcMain.handle('open-external', async (event, url) => {
  try {
    await shell.openExternal(url);
    return { success: true };
  } catch (error) {
    console.error('Error opening external URL:', error);
    return { success: false, error: error.message };
  }
});
```

**2. 预加载脚本（`src/main/preload.js`）：**

暴露 `openExternal` API：

```javascript
contextBridge.exposeInMainWorld('electronAPI', {
  // ... 现有 API ...
  // 在系统浏览器中打开链接
  openExternal: (url) => ipcRenderer.invoke('open-external', url)
});
```

**3. 渲染进程（`src/renderer/js/app.js`）：**

关于模态框中的链接添加 click 事件拦截：

```javascript
// 关于模态框中的链接在系统浏览器中打开
aboutModal.querySelectorAll('a[href]').forEach(link => {
  link.addEventListener('click', (e) => {
    e.preventDefault();
    const url = link.href;
    if (window.electronAPI?.openExternal) {
      window.electronAPI.openExternal(url);
    } else {
      window.open(url, '_blank');
    }
  });
});
```

### 修改文件

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `src/main/main.js` | 修改 | 导入 `shell`，添加 `open-external` IPC 处理器 |
| `src/main/preload.js` | 修改 | 暴露 `openExternal` API |

## 三、Type L 导出模糊背景缩放修复

### 问题描述

Type L 样式导出图片的模糊背景与预览端不一致，导出图片的模糊背景边缘可能出现黑边/透明边。

### 根因分析

**预览端** (`type-L.css`) 使用 CSS `transform: scale(1.5)` 将模糊背景从中心放大 1.5 倍，隐藏 blur 产生的透明边缘。

**导出端** (`type-L-export.js`) 的 `drawBlurredBackground` 函数只做了 cover 裁剪，没有额外缩放，导致 blur 透明边缘可见。

### 修复方案

在 `drawBlurredBackground` 中添加 1.5x 缩放，与预览端 CSS `transform: scale(1.5)` 一致：

```javascript
// 修复前：直接 cover 裁剪到画布大小
ctx.drawImage(img, srcX, srcY, srcW, srcH, 0, 0, canvasWidth, canvasHeight);

// 修复后：放大 1.5 倍后居中绘制，溢出部分被画布裁剪
const scale = 1.5;
const scaledW = canvasWidth * scale;
const scaledH = canvasHeight * scale;
// cover 裁剪基于缩放后尺寸
const offsetX = (canvasWidth - scaledW) / 2;
const offsetY = (canvasHeight - scaledH) / 2;
ctx.drawImage(img, srcX, srcY, srcW, srcH, offsetX, offsetY, scaledW, scaledH);
```

### 修改文件

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `src/renderer/js/styles/type-L-export.js` | 修改 | `drawBlurredBackground` 函数添加 1.5x 缩放 |

## 四、样式 B/F/G/L 图片圆角

### 设计说明

为样式 B、F、G、L 的图片添加 12px 圆角，预览端和导出端效果一致。

### 预览端（CSS）

添加 `border-radius: 12px`：

| 文件 | 选择器 | 说明 |
|------|--------|------|
| `css/type-B.css` | `.frame-wrapper.type-b > img` | Type B 图片圆角 |
| `css/type-F.css` | `.frame-wrapper.type-f img` | Type F 图片圆角 |
| `css/type-G.css` | `.frame-wrapper.type-g > img` | Type G 图片圆角 |
| `css/type-L.css` | `.frame-wrapper.type-l > img:not(.type-l-blur-bg)` | Type L 图片圆角（排除模糊背景层） |

### 导出端（Canvas）

使用 `ctx.roundRect()` + `ctx.clip()` 裁剪，圆角半径按画布宽度比例缩放：

```javascript
const baseScale = canvasWidth / 900;
const cornerRadius = Math.round(12 * baseScale);
ctx.save();
ctx.beginPath();
ctx.roundRect(photoX, photoY, photoWidth, photoHeight, cornerRadius);
ctx.clip();
ctx.drawImage(img, ...);
ctx.restore();
```

**缩放说明**：预览基准宽度 900px 对应 12px 圆角，导出时按实际画布宽度等比缩放（如 6000px 宽 → 80px 圆角），确保视觉比例一致。
